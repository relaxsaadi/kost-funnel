## What "count" and "sample" mean here

- **Count** — the provisional CEILING size of the source-supported item pool
  for that leaf sub-task: the number of genuinely distinct, non-duplicate
  questions the cited slide/exam/practice-book evidence can currently
  support, once drafted and Tier A–gated. It is a ceiling to draft *up to*,
  not a quota that must be filled — if per-item drafting later finds
  thinner support than estimated here, the smaller real yield wins.
- **Sample** — the number of items from that sub-task's pool a single live
  exam sitting would typically draw, for future randomized-exam
  configuration. Illustrative sizing for platform configuration only, not
  itself a scored decision.
- Evidence citations below point back to the specific slide ranges, exam
  question numbers, or practice-book question numbers already traced in
  Stage 1 and independently re-verified in the cross-validation pass — no
  count here is invented without a pointer to that evidence.
