## Derivation basis

This task set is derived only from Function 7.4's own cross-validated Stage 1 evidence in `docs/DGR_STAGE1_FUNCTION_7.4_DRAFT.md` and `docs/DGR_STAGE1_FUNCTION_7.4_CROSSVALIDATION.md`.

Those artifacts record direct visual re-reading of **IATA CBTA Training Guidance / Orientations, Edition 1 (2023), TABLEAU 7.4.A**, PDF pp.29–30 / printed pp.25–26, and independently confirm **37 leaf tasks**. Function 7.4 uses Blocks **0, 4, 6 and 7**. Its Block 0 is not a mechanical copy of Functions 7.1–7.3: it has 16 leaves, omits 0.5.3, and carries Function-7.4-specific wording differences already documented in Stage 1. It must not inherit Function 7.1's 44-task structure, Function 7.2's 23-task structure, or Function 7.3's 33-task structure.
