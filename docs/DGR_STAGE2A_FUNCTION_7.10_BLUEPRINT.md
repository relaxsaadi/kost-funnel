## Method

For each of the 23 leaf sub-tasks, the count is derived from the "KOST
course trace" / "Exam/practice trace" / "Coverage assessment" columns
already recorded in `docs/DGR_STAGE1_FUNCTION_7.10_DRAFT.md`'s sub-task
enumeration tables (independently re-verified in
`docs/DGR_STAGE1_FUNCTION_7.10_CROSSVALIDATION.md`), converted to a
provisional ceiling using the same banding discipline used in
`docs/DGR_STAGE2A_FUNCTION_7.8_BLUEPRINT.md` and
`docs/DGR_STAGE2A_FUNCTION_7.9_BLUEPRINT.md`, anchored to *this function's
own* slide-span and exam/practice cross-reference counts — not copied from
any other function's numbers:

| Stage 1 coverage assessment | Typical evidence pattern in this course | Ceiling band |
|---|---|---|
| Very strong (richest evidence pool; capstone/scenario item(s)) | 7+ slides and/or 4+ exam/practice cross-refs | 5–8 |
| Strong | Dedicated slide(s) (3–7), clear exam/practice trace | 3–5 |
| Adequate | Slide content present but shallow, weak or no exam/practice reinforcement | 1–3 |
| Adequate, shared evidence base only | Same content pool as another sub-task, no independent slide development | 3–4, with a binding distinct-framing restriction |
| Genuinely thin, single-fact slide span (0.1.3) | One slide only, even if wording match is clean | 1, kept minimal per the no-padding rule |
| Thin/wheel-item-only, generic-awareness only (0.6.2) | States an obligation exists, no elaboration, no reinforcement | 1, sample 0–1 |
| Thin/untested, real but minimal evidence, zero reinforcement in either instrument (5.1.2) | 2 slides, no exam/practice cross-ref for either relevant word form | 1, sample 0–1, restricted framing |
| SOURCE GAP | No slide, exam, or practice-book content found anywhere | 0 |

**Sample** = the recommended maximum number of items drawn from that
sub-task's pool for a single exam sitting, the same convention used in
every prior function's Stage 2A blueprint in this program. It is a
per-sub-task draw ceiling, not a claim every sub-task must appear every
sitting.
