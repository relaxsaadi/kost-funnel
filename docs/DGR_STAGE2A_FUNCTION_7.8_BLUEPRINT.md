## Method

For each of the 23 leaf sub-tasks, the count is derived from the "KOST
course trace" / "Exam/practice trace" / "Coverage assessment" columns
already recorded in `docs/DGR_STAGE1_FUNCTION_7.8_DRAFT.md`'s sub-task
enumeration tables (independently re-verified in
`docs/DGR_STAGE1_FUNCTION_7.8_CROSSVALIDATION.md`), converted to a
provisional ceiling using the same banding discipline used in
`docs/DGR_STAGE2A_FUNCTION_7.6_BLUEPRINT.md` and
`docs/DGR_STAGE2A_FUNCTION_7.7_BLUEPRINT.md`, anchored to *this function's
own* slide-span and exam/practice cross-reference counts — not copied from
any other function's numbers:

| Stage 1 coverage assessment | Typical evidence pattern in this course | Ceiling band |
|---|---|---|
| Very strong (capstone item(s) and/or 6+ slides with 5+ cross-refs) | Multi-slide span, worked examples, exam/practice capstone | 6–8 |
| Strong | Dedicated slide(s) (2–6), clear exam/practice trace | 3–4 |
| Strong, single-fact/thin slide span | Genuinely narrow (1 slide), even if wording match is clean | 1, kept minimal per the no-padding rule |
| Adequate | Slide content present but shallow, weak or no exam/practice reinforcement | 2–3 |
| Adequate, shared evidence base only | Same content pool as another sub-task, no independent reinforcement | 2–3, with a binding distinct-framing restriction |
| Adequate/adjacent, imperfect fit | Closest available evidence sits at the boundary with unrelated/over-taught content | 2, restricted framing |
| Generic-awareness-only | States an obligation exists, no procedural detail | 1, sample 0–1 |
| Thin/adjacent, not a clean match (0.4.3) | Passing mention only, wrong pedagogical stage | 1, sample 0–1, restricted framing |
| Partial SOURCE GAP, weaker than a typical "one of several parts evidenced" case (6.2.4) | Only a routine/non-emergency adjacent fact exists; the leaf's own core (emergency-triggered notification) has zero evidence for either named party | 1, sample 0–1, most-restricted framing |
| SOURCE GAP | No slide, exam, or practice-book content found anywhere | 0 |

**Sample** = the recommended maximum number of items drawn from that
sub-task's pool for a single exam sitting, the same convention used in every
prior function's Stage 2A blueprint in this program. It is a per-sub-task
draw ceiling, not a claim every sub-task must appear every sitting.
