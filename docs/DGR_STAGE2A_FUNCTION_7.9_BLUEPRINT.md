## Method

For each of the 24 leaf sub-tasks, the count is derived from the "KOST
course trace" / "Exam/practice trace" / "Coverage assessment" columns
already recorded in `docs/DGR_STAGE1_FUNCTION_7.9_DRAFT.md`'s sub-task
enumeration tables (independently re-verified in
`docs/DGR_STAGE1_FUNCTION_7.9_CROSSVALIDATION.md`), converted to a
provisional ceiling using the same banding discipline used in
`docs/DGR_STAGE2A_FUNCTION_7.6_BLUEPRINT.md` and
`docs/DGR_STAGE2A_FUNCTION_7.7_BLUEPRINT.md`, anchored to *this function's
own* slide-span and exam/practice cross-reference counts — not copied from
any other function's numbers:

| Stage 1 coverage assessment | Typical evidence pattern in this course | Ceiling band |
|---|---|---|
| Very strong ("richest evidence pool"/"most extensively developed and tested [sub-task] in the whole function") | 8+ slides and/or 4+ exam/practice cross-refs, often including a scenario-style capstone item | 6–8 |
| Strong | Dedicated slide(s) (3–7), clear exam/practice trace | 3–5 |
| Strong, shared evidence base only | Dedicated content, but the same slide pool as another leaf | 3, with a binding distinct-framing restriction |
| Adequate | Slide content present but shallow or single-fact; weak/no exam/practice reinforcement | 1–2 |
| Adequate, shared evidence base only | Same content pool as another sub-task, no independent reinforcement | 3, with a binding distinct-framing restriction |
| Adequate, generic-awareness only (0.6.2) | States an obligation/procedure exists, no operational detail | 1, sample 0–1 |
| **Major partial SOURCE GAP (leaf exists, real generic content exists, but the assessment instruments' own capstone content is unsupported)** | Highest qualification level, thin generic-only evidence, unsupported specific content is the leaf's own defining/most-tested content | **1, sample 0–1, hard-restricted to the generic-only supported content, with an explicit prohibition on the unsupported content class** |
| SOURCE GAP | No slide, exam, or practice-book content found anywhere | 0 |

**Sample** = the recommended maximum number of items drawn from that
sub-task's pool for a single exam sitting — a per-sub-task draw ceiling, not
a claim every sub-task must appear every sitting.
