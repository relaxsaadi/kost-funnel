## Derivation basis

This task set is derived only from Function 7.10's own cross-validated Stage 1 evidence in `docs/DGR_STAGE1_FUNCTION_7.10_DRAFT.md` and `docs/DGR_STAGE1_FUNCTION_7.10_CROSSVALIDATION.md`.

Those artifacts record direct visual re-reading of **IATA CBTA Training Guidance / Orientations, Edition 1 (2023), TABLEAU 7.10.A**, PDF p.36 / printed p.32, and independently confirm **23 leaf tasks**. Function 7.10 uses Blocks **0, 3, 5 and 7** with a security-screening-specific selection: Block 0 has 16 leaves; Block 3 uses only 3.4.1–3.4.2; Block 5 uses only 5.1.1–5.1.2; Block 7 uses only 7.1–7.3 and **does not include 7.4**. This task set must not inherit another function's count, block shape, wording or qualification levels.
