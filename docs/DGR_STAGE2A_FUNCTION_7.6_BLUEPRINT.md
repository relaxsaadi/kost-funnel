## Method

For each of the 28 leaf sub-tasks, the count is derived from the "KOST
course trace" / "Exam/practice trace" / "Coverage assessment" columns
already recorded in `docs/DGR_STAGE1_FUNCTION_7.6_DRAFT.md`'s sub-task
enumeration tables (independently re-verified in
`docs/DGR_STAGE1_FUNCTION_7.6_CROSSVALIDATION.md`), converted to a
provisional ceiling using the same banding discipline used in
`docs/DGR_STAGE2A_FUNCTION_7.4_BLUEPRINT.md`, anchored to *this function's
own* slide-span and exam/practice cross-reference counts — not copied from
any other function's numbers:

| Stage 1 coverage assessment | Typical evidence pattern in this course | Ceiling band |
|---|---|---|
| Very strong | Multi-slide (6+ slides) span and/or 5+ exam/practice cross-refs, incl. an exam/practice capstone item | 6–8 |
| Strong | Dedicated slide(s) (3–6), clear exam/practice trace or a named worked example | 3–4 |
| Strong, single-fact/thin slide span | Genuinely narrow (1–2 slides), even if wording match is clean | 1, kept minimal per the no-padding rule |
| Adequate | Slide content present but shallow, weak or no exam/practice reinforcement | 2 |
| Adequate, shared evidence base only | Same content pool as another sub-task, no independent reinforcement | 2, with a binding distinct-framing restriction |
| Generic-awareness-only (0.6.2) | States an obligation exists, no procedural detail | 1, sample 0–1 |
| Thin/adjacent, not a clean match (0.4.3, 4.1.1) | Passing mentions only, wrong pedagogical stage or narrower-than-official scope | 1, sample 0–1, restricted framing |
| SOURCE GAP | No slide, exam, or practice-book content found anywhere | 0 |

**Sample** = the recommended maximum number of items drawn from that
sub-task's pool for a single exam sitting, the same convention used in every
prior function's Stage 2A blueprint in this program. It is a per-sub-task
draw ceiling, not a claim every sub-task must appear every sitting.
