## Derivation basis

This task set is derived only from Function 7.3's own cross-validated Stage 1 evidence in `docs/DGR_STAGE1_FUNCTION_7.3_DRAFT.md` and `docs/DGR_STAGE1_FUNCTION_7.3_CROSSVALIDATION.md`.

Function 7.3 uses Block 0, Block 3 sub-blocks **3.1, 3.2 and 3.3** and Block 7; it does **not** use Function 7.2's 3.4-only structure and does not inherit Function 7.1's 44-task structure.
